Pre-Step A — Launch a brand-new EC2 instance
☁️ AWS CONSOLE — repeat for every run.
1. Sign in to the AWS Console → search EC2 → Instances → Launch instances.
2. Name: lesson1-run1 (change the number each run).
3. AMI: Amazon Linux 2023 (the default Quick Start AMI — not a custom AMI, not a launch
template).
4. Instance type: t2.micro or t3.micro (free-tier eligible).
5. Key pair: choose your existing key pair (or create one once and save the .pem safely).
6. Network settings → Security group:
Allow SSH (port 22) from My IP.
(Optional, for later runbook steps) Custom TCP port 8000 from My IP.
7. Leave storage at default → Launch instance.
8. Wait until Instance state = Running and Status check = 2/2 checks passed.
